# Billora

**فاکتور ساده، خیال آسوده** — یک فاکتورساز فارسی و راست‌چین که اطلاعات را روی دستگاه خودتان نگه می‌دارد.

## اجرا

- `npm install`
- `npm run dev` برای توسعه
- `npm test` برای تست‌های محاسبات، دستورها، پشتیبان و IndexedDB
- `npm run build` برای بررسی TypeScript و ساخت نسخهٔ Production
- `npm run preview` برای دیدن خروجی Production

## امکانات

- ساخت و ویرایش فاکتور، مشتری، اقلام، تعداد اعشاری، قیمت تومان، تخفیف ردیف و تخفیف کلی؛ شماره‌گذاری و تاریخچهٔ محلی.
- کاتالوگ محصولات و قیمت پیش‌فرض، مشخصات فروشگاه و لوگوی قابل چاپ.
- چاپ فاکتور و ذخیره به PDF از پنجرهٔ چاپ مرورگر.
- پشتیبان JSON و بازیابی اعتبارسنجی‌شده؛ بازیابی جایگزین داده‌های فعلی می‌شود.
- PWA با Service Worker برای نگه‌داشتن فایل‌های برنامه پس از بارگذاری اولیه؛ فاکتورها، محصولات و تنظیمات در IndexedDB ذخیره می‌شوند.
- چهار دستور محلی مشخص برای تغییر قیمت، افزودن قلم، تغییر تعداد و حذف محصول. تغییر قیمت و حذف، پیش از اجرا نیازمند تأیید است.
- ورود گفتاری اختیاری با Web Speech API در مرورگرهای پشتیبانی‌شده. این ویژگی مدل گفتار محلی ندارد، ممکن است برای تشخیص به اینترنت و مجوز میکروفن نیاز داشته باشد و آفلاین یا در همهٔ مرورگرها تضمین‌شده نیست؛ متن تشخیص‌داده‌شده خودکار اجرا نمی‌شود.

## حریم خصوصی و محدودیت‌ها

Billora سرور، حساب کاربری، همگام‌سازی ابری، API هوش مصنوعی یا هزینهٔ اشتراک ندارد. اطلاعات روی همان مرورگر و دستگاه است؛ پاک‌کردن داده‌های مرورگر یا خرابی دستگاه می‌تواند آن را از دسترس خارج کند. مرتب فایل پشتیبان بگیرید و آن را امن نگه دارید. کارکرد آفلاین به بارگذاری اولیهٔ موفق، پشتیبانی Service Worker و نگه‌داری فایل‌ها توسط مرورگر وابسته است.

## استقرار

پروژهٔ Vite آمادهٔ استقرار روی Vercel است (`vercel.json` و خروجی `dist`). آدرس میزبانی فقط پس از استقرار واقعی باید اعلام شود.
