# Billora

**فاکتور ساده، خیال آسوده** — یک فاکتورساز فارسی و راست‌چین که اطلاعات را روی دستگاه خودتان نگه می‌دارد.

## اجرا

- `npm install`
- `npm run dev` برای توسعه
- `npm test` برای تست‌های محاسبات، دستورها، پشتیبان و IndexedDB
- `npm run build` برای بررسی TypeScript و ساخت نسخهٔ Production
- `npm run preview` برای دیدن خروجی Production
- `npm run model:download` برای نصب دستی مدل گفتار آفلاین (در زمان build خودکار انجام می‌شود؛ در گیت ذخیره نمی‌شود)
- `npm run model:check` برای بررسی سالم‌بودن فایل‌های مدل نصب‌شده

## امکانات

- ساخت و ویرایش فاکتور، مشتری، اقلام، تعداد اعشاری تا سه رقم، قیمت صحیح به تومان، تخفیف ردیف و تخفیف کلی؛ شماره‌گذاری و تاریخچهٔ محلی.
- کاتالوگ محصولات و قیمت پیش‌فرض، مشخصات فروشگاه و لوگوی قابل چاپ.
- چاپ فاکتور و ذخیره به PDF از پنجرهٔ چاپ مرورگر.
- پشتیبان JSON و بازیابی اعتبارسنجی‌شده؛ بازیابی جایگزین داده‌های فعلی می‌شود.
- PWA با Service Worker برای نگه‌داشتن فایل‌های برنامه پس از بارگذاری اولیه؛ فاکتورها، محصولات و تنظیمات در IndexedDB ذخیره می‌شوند.
- چهار دستور محلی مشخص برای تغییر قیمت، افزودن قلم، تغییر تعداد و حذف محصول. تغییر قیمت و حذف، پیش از اجرا نیازمند تأیید است.
- ورود گفتاری اختیاری با Web Speech API در مرورگرهای پشتیبانی‌شده. این ویژگی مدل گفتار محلی ندارد، ممکن است به اینترنت و مجوز میکروفن نیاز داشته باشد و آفلاین یا در همهٔ مرورگرها تضمین‌شده نیست. بعضی مرورگرها ممکن است صدا را به سرویس گفتار خود بفرستند؛ متن تشخیص‌داده‌شده خودکار اجرا نمی‌شود.

## تشخیص گفتار آفلاین (شنوا کوچیک ۱.۵)

افزون بر Web Speech API، یک موتور گفتار کاملاً روی‌دستگاه با مدل [`Shenava-Koochik-v1.5-RNNT-sherpa-onnx`](https://huggingface.co/Reza2kn/Shenava-Koochik-v1.5-RNNT-sherpa-onnx) (int8، اجرا با `onnxruntime-web` داخل Web Worker) وجود دارد:

- صدا از مرورگر بیرون نمی‌رود و پس از نصب مدل، بدون اینترنت کار می‌کند.
- متن نهایی فقط داخل ورودی فرمان می‌نشیند؛ هیچ دستوری خودکار اجرا نمی‌شود و اجرای دستی با «اجرای دستور» انجام می‌گیرد.
- مدل در زمان build دانلود می‌شود (`prebuild` → `scripts/download-shenava-model.mjs`) و اگر دانلود ناموفق باشد، build متوقف نمی‌شود؛ فقط موتور آفلاین غیرفعال می‌ماند (ورودی متنی و Web Speech API کار می‌کنند).
- صفحهٔ تست مستقل: `/test-shenava.html` (با `npm run dev`). جزئیات معماری، هدرهای Cross-Origin، چک‌لیست تست روی iPhone/Android و محدودیت‌های تأییدنشده در [`docs/shenava-offline-speech.md`](docs/shenava-offline-speech.md).

## حریم خصوصی و محدودیت‌ها

Billora سرور، حساب کاربری، همگام‌سازی ابری، API هوش مصنوعی یا هزینهٔ اشتراک ندارد. به‌جز استثنای احتمالی سرویس گفتار خود مرورگر، اطلاعات برنامه روی همان مرورگر و دستگاه است؛ پاک‌کردن داده‌های مرورگر یا خرابی دستگاه می‌تواند اطلاعات را از دسترس خارج کند. مرتب فایل پشتیبان بگیرید و آن را امن نگه دارید. کارکرد آفلاین به بارگذاری اولیهٔ موفق، پشتیبانی Service Worker و نگه‌داری فایل‌ها توسط مرورگر وابسته است.

- **GitHub Pages:** گردش‌کار `.github/workflows/pages.yml` روی شاخهٔ `arena/e82b60fd-billora` تست و ساخت را اجرا می‌کند. برای فعال‌کردن انتشار، در تنظیمات مخزن به **Settings → Pages → Build and deployment → Source** بروید و **GitHub Actions** را انتخاب کنید. ساخت برای مسیر پروژهٔ GitHub Pages پیکربندی شده است.
- **Vercel:** پروژه با `vercel.json` و خروجی `dist` قابل استقرار است؛ انتشار نیازمند اتصال/احراز هویت واقعی در حساب Vercel است.
